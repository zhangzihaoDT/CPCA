## 列表页

```text
https://www.cpcaauto.com/news.php?types=csjd&anid=128&nid=21&page=N
```

- 车市解读 → 周度 → 车市扫描。
- 每页 20 条，按发布时间倒序。
- 截至 2026-10-22，共 336 条、17 页。
- 列表项结构：

```html
<li class="q">
  <span>2026-10-21 </span>
  <a href="newslist.php?types=csjd&id=4359">
    &nbsp;&nbsp;【周度分析】车市扫描(20261012-1018)
  </a>
</li>
```

- 日期为列表发布时间，标题括号内为文章覆盖的周区间。
- 标题区间可能有一位多余数字，例如 `(202600201-0208)`，按 `2026-02-01~02-08` 归一化。

## 文章页

```text
https://www.cpcaauto.com/newslist.php?types=csjd&id=<article_id>
```

- 标题在 `<div class="tit">`。
- 发布时间在 `发布时间：YYYY-MM-DD HH:MM:SS`。
- 正文在 `<div class="text">`。
- “本周车市概述”在正文顶部，后面是 `1.`、`2.` 等详细章节。

## 概述块提取

1. HTML 转文本，保留换行。
2. 找到 `本周车市概述`。
3. 截取到第一个 `1.20XX年` 章节标题之前。
4. 合并空白，保留两段/四段文字。
5. 归一化：
   - `较上月` → `较上月同期`（不重复替换 `较上月同期`）。
   - 如果 NEV 段落内嵌 `零售渗透率X%` 和 `批发渗透率Y%`，补一个 `渗透率：` 段。
   - 确保以 `乘用车：` 或 `初步统计：` 开头。

## 结构化概述的起点

- **2024-01-17** 的文章（id=3347，覆盖 2024-01-01~01-14）开始有可解析的 `乘用车：` / `新能源：` 结构化概述。
- 2024-01-11 及以前（2020–2023）是旧格式：
  - 2020–2021：`本周车市概述` 后直接是正文，没有摘要；
  - 2022–2023：只有一行乘用车摘要，缺新能源/YTD；
  - 2024 年第一周（id=3342，覆盖 1/1–1/7）仍是旧格式。
- 2024-01-17 以后至 2026 年可按当前 schema 解析；2020–2023 只能保留原始 HTML 或另做 legacy 解析。
