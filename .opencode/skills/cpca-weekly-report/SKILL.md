# CPCA Weekly Report

从标准表生成 HTML 简报。三段指标读取 `data/standard_dataset.csv`，统计区间与报告状态读取最新 JSON；不直接读取原始文本，也不手工改数。

## 路径约定

本文中的 `data/`、`reports/`、`scripts/` 均相对项目根目录，命令在项目根目录执行。

## 工作流

1. 运行数据校验：

   ```bash
   python3 scripts/validate_data.py
   ```

2. 生成标准表：

   ```bash
   python3 scripts/build_standard_dataset.py
   ```

   输出 `data/standard_dataset.csv`：每个周快照 3 行（最新区间、当月累计、当年累计）；每月首周 2 行（当周、当年，当周即当月累计）。

3. 确认最新区间：`data/` 中 `period.end` 最大者为本期。
4. 生成报告：

   ```bash
   python3 scripts/render_report.py
   ```

   默认输出 `reports/<period.end>.html`。如需重生成历史某期：

   ```bash
   python3 scripts/render_report.py --period 2026-10-18 --out reports/2026-10-18.html
   ```

5. 打开 HTML 抽查：
   - 标题、数据统计区间、（初步统计）正确。
   - 最新区间、当月累计、当年累计三段与标准表一致；首周无当月。
   - 最新区间同比标“（估算）”，当月、当年不标。
   - 缺失值显示“未发布”，没有补零。
   - 页脚数据来源与单位说明正确。
   - 品牌角标为 CPCA。
6. 汇报输出路径和仍需人工确认的 flags。

## 报告结构

1. 页头：报告名、数据统计区间、（初步统计）。
2. 最新区间（每月首周为“当周”）：乘用车市场零售、新能源市场零售；数值 + 同比。非首周的同比标“（估算）”。
3. 当月累计：同一组两项指标；每月首周没有这一段。
4. 当年累计：同一组两项指标。
5. 页脚：数据来源与单位说明。

报告只保留乘用车零售、新能源零售两条线。批发、渗透率、生产、校验 flags 留在 JSON 审计层，不进入简报正文。

## 署名规则

| 场景 | 写法 |
| --- | --- |
| 数据发布主体 | CPCA（乘联会） |
| 品牌角标 | CPCA |
| 页脚数据来源 | 数据来源：乘联会（CPCA） |
| 组织关系 | CPCA 是 CADA（中国汽车流通协会）下属的乘用车市场信息联席分会 |

- 数据一律归 CPCA。
- CADA 只出现在组织关系说明中。
- 不使用“CADA 数据”“CADA 乘联会”等写法。
- 不把上级协会写成数据发布方。

## 数据表现规则

- 报告中的数值必须来自标准表，不得在 HTML 中手工修改。
- 原文没有的指标写“未发布”，不补零、不插值。
- 报告只展示乘用车市场零售、新能源市场零售；批发、渗透率、生产不进入简报正文。
- 标准表可能缺少“当年累计”行（原文未发布 YTD）；报告只渲染存在的段落，不补零、不补数。
- “最新区间”是 CPCA 官方发布区间，不保证 7 天；报告不按自然周补齐，不构造缺失周。
- 非首周“最新区间”的同比由相邻两期累计同比反推，标“（估算）”；原文累计同比为整数百分比，误差可能约 ±1–2 个百分点。“（估算）”仅指同比反推，不是预测。
- 每月首周当周即当月累计，报告显示当周、当年两段，不单列当月。
- 当月累计、当年累计的同比为原文发布值，不加“估算”。
- 校验 flags、9 月基数差异等审计信息保留在 JSON/CSV，不在简报正文中删除或改写。

## 视觉约束

- 浅色背景、白色卡片、深蓝标题、蓝灰正文、暖金点缀。
- 数据优先，排版简洁，不使用装饰性图形干扰读数。
- 目标是桌面端一屏读完：控制标题、区块间距和卡片高度；短屏（高度 ≤820px）自动压缩。
- 单文件 HTML，CSS 内联，不依赖外部 CDN、字体或脚本，离线可直接打开。
- 桌面与移动端可读，打印时不截断卡片。
- 品牌角标统一 `CPCA`。

## 禁止事项

- 不直接编辑 `reports/*.html` 中的数据；改数据请改源 JSON，重建 `data/standard_dataset.csv` 后重新生成。
- 不添加数据集之外的销量、排名、预测或因果判断。
- 不在数据层删除或隐藏校验 flag；简报正文可以不展示，但 JSON 必须保留。
- 不把缺失值写成 0。
- 不以 CADA 名义发布数据。
