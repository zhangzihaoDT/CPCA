# 数据观察

## 2026-01-19 至 2026-03-08：6 个官方未发布周

记录日期：2026-10-22

### 发现

2026 年 1 月 19 日至 3 月 8 日之间，官网“车市扫描”没有发布连续周报，形成 6 个自然周的空档：

| 自然周 | 官网情况 |
| --- | --- |
| 1/19–1/25 | 无文章 |
| 1/26–2/1 | 仅 2/1 被 2/1–2/8 覆盖，无独立周报 |
| 2/9–2/15 | 无文章 |
| 2/16–2/22 | 无文章（2026 年春节为 2/17） |
| 2/23–3/1 | 无文章 |
| 3/2–3/8 | 仅被 3/1–3/15 累计覆盖，无独立周报 |

### 原因

- 前两周：春节前停更/发布节奏。
- 中间两周：春节假期（2026 年春节为 2 月 17 日）。
- 后两周：节后恢复期。
- 不是抓取遗漏；官网列表页在这段时间没有对应文章。

### 对数据的影响

- 周度快照从 2026-01-18 直接跳到 2026-02-08，再到 2026-03-15。
- 标准表不为这 6 周构造数据，不补 7 天周序列。
- 当前 134 个正式区间 = 103 个周度快照 + 31 个月度收盘；空档只影响 2026 年周度快照，不代表全部数据缺失。
- 其他月末周（3/23–3/31、4/27–4/30 等）有月度收盘，不属于“官网未发布”，只是不进入周表。

### 证据

- 2026-01-21 文章（id=4114）覆盖 1/12–1/18。
- 2026-02-11 文章（id=4131）覆盖 2/1–2/8。
- 2026-03-18 文章（id=4157）覆盖 3/1–3/15。
- 列表页在 1/21 与 2/11 之间、2/11 与 3/18 之间没有周度文章。

## Legacy V2：2022–2023 覆盖与缺口

记录日期：2026-10-22

### 覆盖

- 2022–2023 共 98 个唯一区间：13 个月度收盘 + 85 个周度快照。
- 98 个区间全部有乘用车零售/批发；46 个含新能源，44 个含 YTD。

- 2022-05-31 文章（id=2772）同时包含 `5月1-31日` 月度收盘和 `6月1-5日` 下月首段；Legacy V2 已拆成两个区间，补回 6/1–6/5。
- 2022-06-12、2022-10-16 等文章同时包含本周区间和本月累计；累计段不当作新的周区间。
- 2023-02-19 等文章在同一 period 下另起一段新能源数据；主段整块解析，新能源字段保留。

### 已知缺口

- 2022-10-01 至 2022-10-07 官网没有独立摘要；2022-10-16 文章只给 `10月8-16日` 和 `10月1-16日` 累计。
- 不用累计差反推 10/1–10/7；Legacy 保留缺口，不补数。
- 旧格式原文本身存在不完整区间，历史采集层允许缺失，不改变正式周度简报口径。
